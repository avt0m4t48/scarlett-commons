# Прогоны игры

Как далеко движок продвигается на реальной игре; отчёт составляется так, чтобы не называть и не разглашать
ничего из неё.

**Сейчас:** в `builds/` пока не зарегистрирована ни одна сборка, поэтому отчёты принимаются как `unregistered`,
пока мейнтейнер не зарегистрирует первую сборку по двум совпавшим хешам. Профиль сборки, который нужен для
`tools/local_run.py --profile` для игры, на которой разрабатывался движок, это продолжение Leonida
(github.com/ubiquitarianism/leonida): клонируйте его и передайте его папку.

1. **Сборки задаются хешами.** `builds/<id>.json` регистрирует сборку по SHA-256 и размеру её исполняемого файла,
   под нейтральным идентификатором. Мейнтейнер добавляет сборку после того, как двое подтвердили хеш по своим
   копиям.
2. **Проверьте свою копию:** `python3 -I tools/check_build.py <your install dir> <list>`, где список состоит из
   одной строки `<exe_sha256>  <exe name>`. Сообщайте только о сборке, которая совпадает.
3. **Запустите одной командой** на своей машине:

   ```
   python3 -I tools/local_run.py --profile <checkout with the title's build profile> --game <your copy> --work <folder>
   ```

   Она собирает вашу копию с движком этого репозитория, запускает её с трассировкой и отчётом о падении и пишет
   `<folder>/report/<login>.json` по разрешённому списку полей: достигнутая стадия (до `first-frame` определяется
   сама; для `menu`, `in-world` или `playable` передайте `--stage-reached`), fps, где остановилось (модуль и
   смещение) и число шейдеров по причинам отказа. Прочитайте отчёт, прежде чем отправлять.
4. **Отчёт:** добавьте `title-runs/<build id>/<engine commit>/<your login>.json` в pull request (формат в
   `tools/title_runs.py`): самая дальняя **стадия**, fps, где **остановилось** (`module+0xOFFSET reason`) и
   короткие заметки. Бот отклоняет отчёт, имя которого не совпадает с именем автора.
5. **Подтверждение:** стадия засчитывается для пары (сборка, коммит), когда двое разных людей сообщают, что
   достигли её или дальше. Страница хода работ показывает самую дальнюю подтверждённую стадию для каждой сборки.

Стадии по порядку: `loads`, `imports-resolved`, `device-created`, `first-frame`, `menu`, `in-world`, `playable`.

**Никогда не включайте в отчёт:** скриншоты, видео, звук, логи, цитирующие код или данные игры, дампы, листинги
шейдеров, содержимое файлов и то, где взять игру. Смещения и однострочной причины достаточно, чтобы найти
проблему в вашей собственной копии.

**Профили**, превращающие вашу собственную копию в сборку, которую может запустить движок (списки файлов, стадии
сборки), ведутся вне этого репозитория; см. engine/README.md.
